# Style reference

Every option below can be set in a preset, in a style file, or on the command
line with `-s path=value`. Layers merge in that order, with `-s` winning. A style
file may begin with `preset: <name>` (or `none`) to say which preset it builds on;
`--preset` on the command line overrides it.

Each section ends with the Typst that implements its options. That matters when
you add your own code through `advanced.preamble`, or when a Typst error names a
construct and you need the option behind it. `typesep explain <path>` shows the
same mapping for a single option.

This file is generated by `make docs`. Edit the option table in
`crates/typesep-style/src/schema.rs` and the Typst notes in
`crates/typesep-typst/src/preamble.rs`.

## Typography

| option | accepts | default | what it does |
| --- | --- | --- | --- |
| `typography.fontSize` | a length such as 0.6in, 12pt, 1.5em (units: pt, bp, mm, cm, in, pc, em, ex, sp), greater than 0 | `"10pt"` | Body font size. |
| `typography.leading` | a multiplier like 1.15, or an absolute length like 13pt, greater than 0 | `1.15` | Line spacing, as a multiplier or an absolute baseline distance. |
| `typography.justify` | true or false | `true` | Justify body text (off gives a ragged right edge). |
| `typography.hyphenate` | true or false | `true` | Allow hyphenation at line breaks. |
| `typography.language` | text | `"auto"` | Babel language, which selects the hyphenation patterns. "auto" follows the language the document names (the first one's, in a merge). |
| `typography.parIndent` | a length such as 0.6in, 12pt, 1.5em (units: pt, bp, mm, cm, in, pc, em, ex, sp) | `"1.2em"` | First-line indent of paragraphs. |
| `typography.parSkip` | a length such as 0.6in, 12pt, 1.5em (units: pt, bp, mm, cm, in, pc, em, ex, sp) | `"0pt"` | Extra vertical space between paragraphs. |
| `typography.raggedBottom` | true or false | `true` | Let the last line of a page float instead of stretching to the bottom. |
| `typography.microtype.protrusion` | true or false | `true` | Margin kerning (characters hang slightly into the margin). |
| `typography.microtype.expansion` | true or false | `true` | Subtle glyph width adjustment to improve justification. |
| `typography.penalties.widow` | a whole number | `10000` | Penalty for a widow line. 10000 forbids it. |
| `typography.penalties.club` | a whole number | `10000` | Penalty for an orphan line. 10000 forbids it. |
| `typography.penalties.hyphen` | a whole number | `50` | Penalty for breaking a word. Higher means fewer hyphens. |
| `typography.tolerance` | a whole number | `2000` | How much looseness TeX tolerates in a line before complaining. |
| `typography.emergencyStretch` | a length such as 0.6in, 12pt, 1.5em (units: pt, bp, mm, cm, in, pc, em, ex, sp), 0 or more | `"3em"` | Extra stretch allowed on a final pass to avoid overfull lines. |

Under the hood:

- **document** (set text(size:) with top-edge 1em and a baseline bottom edge, so the line pitch is the body size plus the leading whatever the font's own ascender; set document() for the PDF metadata. Typst has no document class, so advanced.documentClass is ignored): `typography.fontSize`.
- **language and hyphenation** (set text(lang:) selects the hyphenation patterns, and set text(dir: rtl) the direction of a document written right to left; set text(hyphenate:) turns hyphenation off, as it is, with a note, for a language Typst has no patterns for): `typography.language`, `typography.hyphenate`.
- **paragraph shape** (set par(leading:, spacing:, justify:, first-line-indent:) and set text(costs:), where TeX's default penalties (150, 150, 50) are 100%. Typst never stretches a page, so typography.raggedBottom false, tolerance and emergencyStretch have nothing to drive): `typography.leading`, `typography.parIndent`, `typography.parSkip`, `typography.justify`, `typography.raggedBottom`, `typography.penalties.*`, `typography.tolerance`, `typography.emergencyStretch`.
- **microtypography** (set text(overhang:) for protrusion; Typst has no font expansion, so typography.microtype.expansion has nothing to drive): `typography.microtype.protrusion`, `typography.microtype.expansion`.
